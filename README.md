# Syllable Tree Builder

An interactive React and TypeScript app for building onset-rhyme syllable trees.

## Features

- add, remove, duplicate, and reorder syllables
- onset, nucleus, and coda fields
- complex constituents using space-separated segments
- optional primary and secondary stress
- automatic omission of empty onset and coda branches
- live SVG preview
- PNG and SVG export
- qtree-style LaTeX export
- saved work in localStorage
- example presets

## Windows commands

```bat
npm.cmd install
npm.cmd run dev
```

Test the production build:

```bat
npm.cmd run build
```
